# 分析报告说明

`report.ps1` 是本 Skill 的主交付物：一次运行，扫描所有固定磁盘，生成 Markdown 和深色单文件 HTML 两份报告。

## 运行

```powershell
cd skills\windows-disk-cleaner\scripts

# 全盘（默认扫描所有固定分区）
.\report.ps1

# 指定磁盘
.\report.ps1 -Drives C:,G:

# 只要 Markdown，不要 HTML
.\report.ps1 -NoHtml

# 调整大文件列表数量与二级目录阈值
.\report.ps1 -TopFiles 20 -Top 15

# 细查 C 盘：只对最大的二级目录继续下钻，找出 AppData、模型、工程缓存等具体大户
.\report.ps1 -Drives C: -DrillDown -DrillDownTop 3

# 大盘超时保护（秒），超时则用已扫描到的部分结果继续
.\report.ps1 -ScanTimeoutSec 600
```

输出位置：`%LOCALAPPDATA%\WindowsDiskCleaner\reports\disk-report-<时间戳>.md / .html`

## 性质归类

报告会把每个目录/文件按内容性质打标签并着色，全篇统一色板：

| 性质 | 处置建议 |
|---|---|
| AI 模型权重（safetensors/ckpt/gguf…） | **不建议删除**，迁移到数据盘 |
| 游戏引擎资产（UnrealEngine/Unity…） | 归档或用启动器卸载 |
| 项目目录 / 源代码 / 个人资料 | 保留，最多迁移 |
| 回收站 | 确认无需恢复后清空 |
| 包管理 / 浏览器 / IDE / 应用缓存 | 可清（部分需先关应用） |
| 虚拟磁盘（WSL vhdx / Docker） | 专用工具压缩，不要手删 |
| Git 仓库数据 | 用 `git gc --aggressive`，不要手删 `.git/objects` |
| 临时文件 / 崩溃转储 | 低风险可清 |

## 图表说明

- **磁盘卡片（环形图）**：已用比例与告警状态；<5% 严重告警、<10% 告警、<20% 注意
- **空间分布（堆叠条）**：该盘前若干个目录占"已用空间"的比例，灰色段为其余零散文件
- **空间大户卡**：按顶级目录的实际占用排序，卡片直接显示占本盘已用空间的比例、完整路径和处理建议；前四项默认展开
- **子目录明细**：展开空间大户卡即可看到占用较多的直接子目录；每项标出体积、完整路径、内容性质及对应建议
- **深度大户**：使用 `-DrillDown` 时，报告会对最大的二级目录单独继续扫描，列出其中超过 1 GB 的真实子目录；适合回答“C 盘到底是哪些目录大”
- **清理档位卡**：按风险分档汇总，附"怎么清"的具体操作指引

## 隐私

报告完全在本地生成，包含本机文件路径但**不会上传到任何服务**。若要把报告发给别人，注意其中包含你的目录结构与文件名，自行斟酌。

## 依赖

gdu（可选但推荐）：负责目录体积与大文件统计。安装：仓库根目录运行 `.\setup-gdu.ps1`。
未安装 gdu 时报告仍会生成，但缺少目录排行、二级大户和大文件列表（仅剩清理计划部分）。
